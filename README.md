# K5 Web-ohjelmoinnin toimeksianto

## Elden Ring hahmon luonti

Sivulla voit luoda oman Elden ring hahmosi. Valitse ensimmäiseksi mikä kuvaa sinua parhaiten ja sivu hakee Elden Ring API classes sivulta https://eldenring.fanapis.com/api/classes sopivan profiilin sinulle. Seuraavaksi tulee käyttöösi 20 osaamispistettä, jotka jaetaan neljälle eri taidolle.

## Ohjelmointi

Sovellukseen luontiin käytetty HTML, CSS ja Javascript. Elden Ring api tiedot haetaan Json muodossa.
